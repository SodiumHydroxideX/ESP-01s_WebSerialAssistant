## 📖 项目简介

本项目为嵌入式开发者提供一个**简单、易用、功能强大**的串口调试助手。与传统串口调试助手不同，它完全运行在 **ESP-01S** 模块上：

- **无需 USB 转 TTL 线缆**：ESP-01S 通过 WiFi 与电脑/手机通信，实现无线调试。
- **便捷交互**：可随时通过浏览器进行参数调节、命令下发、数据反馈查看。
- **特别适合调参场景**：摆脱物理连线束缚，让调参过程更加流畅。

> 💡 **注意**：本项目是 **100% Vibe Coding** 的产物，若遇到 Bug 欢迎提 Issue 反馈。

## 🔧 项目原理

1. ESP-01S 接收单片机发送的串口数据（默认波特率 **115200**）。
2. ESP-01S 将串口数据转发到 WebSocket 服务。
3. WebSocket 将数据推送至前端页面，同时前端下发的指令也经此路径反向传输。

## 🚀 快速上手
下面将指导您完成环境配置、固件烧录以及首次使用调试界面的全流程。

### 📋 准备工作

- **硬件**：一块 **ESP-01S** 模块，以及一个 **USB 转 TTL 串口模块**（用于烧录固件）。
- **软件**：安装 **Visual Studio Code**，并在其中安装 **PlatformIO IDE** 扩展。
- **项目源码**：将项目克隆或下载到本地。


### ⚙️ 第一步：配置 PlatformIO 环境

1. **打开项目**：在 VS Code 中，选择 `File` → `Open Folder`，打开您刚克隆下来的项目文件夹。
2. **确认项目结构**：核心代码位于 `src/` 目录，`main.cpp` 为主程序，`index_html.h` 包含了内置网页。
3. **检查板型配置**：`platformio.ini` 中 `board` 字段应设为 `esp01_1m`。若文件缺失，可参考以下模板创建：


```
[env:esp01_1m]
platform = espressif8266
board = esp01_1m
framework = arduino
extra_scripts = tools/generate_html.py
lib_deps = links2004/WebSockets@2.7.2
board_build.flash_mode = dout
board_upload.resetmethod = nodemcu
upload_speed = 115200
monitor_speed = 115200
monitor_dtr = 0
monitor_rts = 0
debug_tool = esp-builtin
```
4. **安装依赖**：PlatformIO 会自动解析并下载所需库，等待右下角进度条完成即可。

### 🔥 第二步：烧录固件到 ESP-01S

1. **硬件连接**：按如下方式连接 ESP-01S 与 USB 转 TTL：

- ESP-01SUSB 转 TTLVCC3.3VGNDGNDTXRXRXTXGPIO0GND（烧录时必须拉低）

> **注意**：烧录完成后，**请断开 GPIO0 与 GND 的连接**，否则模块无法正常启动。
2. **编译与上传**：

- 在 VS Code 底部状态栏，点击 **`√`（打勾图标）** 进行编译。
- 编译成功后，点击 **`→`（右箭头图标）** 将固件上传到 ESP-01S。
- 等待控制台输出 `SUCCESS`，即表示烧录完成。
3. **启动模块**：断开 GPIO0 与 GND 的连接，重新给 ESP-01S 上电，模块会以 **AP 模式** 启动，默认热点名称为 `ESP-01S_Control`。

### 🌐 第三步：打开调试界面
模块支持 **AP 模式** 和 **STA 模式**（固件默认同时开启两种模式），您可根据网络环境选择连接方式。

#### 方式一：AP 模式（无路由器，适用于现场调试）

1. **连接 WiFi**：使用电脑或手机连接到 ESP-01S 发出的热点，默认 SSID 为 `ESP-01S`（密码可在代码中修改）。
2. **访问网页**：打开浏览器，在地址栏输入 **`192.168.4.1`**，即可加载内置调试界面。

#### 方式二：STA 模式（已有 Wi-Fi 网络，适用于远程访问）
无需重新烧录固件，只需在调试界面中完成 Wi-Fi 配置：

1. **进入调试界面**：先通过上述 **AP 模式** 连接模块，打开调试界面。
2. **配置 Wi-Fi**：在界面中找到 Wi-Fi 设置区域，输入您家中的 Wi-Fi 名称和密码，点击保存。
3. **等待连接**：模块将在约 **10 秒** 内连接上路由器，连接成功后界面会显示路由器分配的 IP 地址（例如 `192.168.1.105`）。
4. **切换访问**：将您的电脑或手机连接到**同一 Wi-Fi 网络**，在浏览器中输入上一步获取的 IP 地址，即可继续访问调试界面。

> 💡 **提示**：
> - 配置成功后，模块会记住 Wi-Fi 信息，下次上电会自动连接路由器，同时 AP 热点依然可用。
> - 若 Wi-Fi 配置失败或路由器不可用，模块仍会开启 AP 热点，您可随时重新通过 `192.168.4.1` 进入调试界面修改配置。
> - AP 模式适合现场调试，STA 模式适合通过家庭内网远程访问，两者互不干扰。

### 💡 使用小贴士

- **连接不上？** 如果断开热点后重新连接，页面显示“未连接”，请点击右上角的“设置”按钮，再点击“重新连接”即可。
- **布局自动保存**：所有窗口的位置和设置都会保存在浏览器的 `localStorage` 中，刷新页面无需重新调整。
- **离线使用**：ESP-01S 可以以 AP 模式运行，即使没有互联网，只要设备连接到其热点，所有调试功能均可正常使用。
